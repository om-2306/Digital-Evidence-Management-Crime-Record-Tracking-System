# Digital-Evidence-Management-Crime-Record-Tracking-System
The Digital Evidence Management System is a Python-based console application developed to manage criminal investigation cases and their associated digital evidence efficiently. The system enables law enforcement personnel to create, update, track, and manage criminal cases while maintaining evidence records and generating investigation reports.

Features Developed
🔹 Case Management
Add new criminal cases
View all registered cases
View detailed information of a specific case
Update investigation status
Update case priority levels
Add investigation notes
Delete existing cases
Search cases using different criteria
🔹 Evidence Management
Add digital evidence linked to a case
Store evidence details securely
Track evidence records
Associate multiple evidence items with a case
Verify evidence existence before operations
🔹 Investigation Tracking
Monitor investigation progress
Manage investigation statuses:
Open
In Progress
Under Review
Closed
Reopened
Assign priority levels:
Low
Medium
High
Critical
🔹 Search & Filtering
Search by crime type
Search by assigned officer
Search by investigation status
Search by priority level
Search by suspect name
🔹 Report Generation
Generate case reports
Generate active case reports
Generate summary reports
Export reports into text files
Export case and evidence data into CSV format
🔹 Data Storage
JSON-based persistent storage
Automatic data loading and saving
CSV export functionality for analysis and reporting
🔹 User Interface
Interactive menu-driven console interface
Input validation for all fields
User-friendly prompts and messages
Error handling and success notifications
